# Design notes

The plans the features were built from (2026-10), kept so the code's `plan/<name>.md` references
lead somewhere. They are history: when one disagrees with the code, the code wins, and nobody
updates these after the feature ships. `fab-version-lock.md`, referenced from To Fab's release
lock code, was never saved here; that code's comments describe it.

Exception: `cad-3d-viewer.md` (2026-11-10) is a live plan, kept up to date while its sessions
run; its Progress table is the handoff between Claude sessions.

Reference images and the Gemini roadmap files from the same folder are in Harel's setup kit, not
in the repo.
